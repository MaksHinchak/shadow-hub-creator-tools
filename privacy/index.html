Privacy Policy

Last updated: September 23, 2026.

Shadow Hub Creator Tools is a private, locally operated integration used by the owner of the Shadow Hub channel. It uses Google's OAuth authorization and the YouTube Data, Analytics, and Reporting APIs. It is not offered as a public account service. This policy describes the operator's use of the integration; the underlying open-source package is provided by its separate maintainer.

Data accessed

Depending on the owner's authorized actions, the integration can access channel identity and metadata; videos, playlists, captions and comments; channel performance, audience and monetary analytics; and reports. It may upload owner-selected video and thumbnail files, and change video metadata or comments when the owner directs it to. The OAuth consent screen lists the permissions requested.

Purpose and use

Data is used to manage the owner's channel, publish owner-selected content, answer the owner's questions about channel performance, and help plan content. The integration does not sell YouTube API data or use it to serve ads. Visitors to this website cannot connect a Google Account or submit YouTube data here.

Storage and retention

The OAuth client configuration and authorization token are stored on the owner's computer in the ~/.youtube-mcp/ directory while authorization remains active and needed. The integration may save owner-requested reports or other API results locally. There is no application-operated remote database for YouTube account data. The operator deletes or refreshes stored YouTube metadata and other non-statistical API data within 30 calendar days. Analytics, reporting data, and statistics may be retained longer while needed for the authorized purpose; the operator rechecks authorization and the relevant content at least every 30 days. Google and OpenAI may retain data under their respective policies and account settings.

Processing by the assistant and third parties

When the owner uses the integration through Codex, requested API results and owner-provided instructions may be processed by OpenAI to provide the assistant response. Google processes API requests and OAuth authorization. The operator does not independently send channel data to advertisers or sell it to data brokers. The website is hosted by GitHub Pages, which may process ordinary web-request information under GitHub's own policy.

Control, revocation, and deletion

The owner can revoke this integration's access at Google Account security settings at any time. The owner can also request deletion of locally retained YouTube API data through the contact below; the operator will delete it as soon as possible and within seven calendar days. To remove locally stored authorization, delete ~/.youtube-mcp/token.json; to remove the downloaded client configuration, delete ~/.youtube-mcp/client_secret.json. Separately saved reports or API results must also be deleted from their saved locations. Revocation stops future API access; the operator will remove locally retained authorized API data within seven calendar days after learning of revocation. Deleting local data does not delete content stored by YouTube. The owner can use YouTube to remove published content. For data in Codex, use the applicable OpenAI account controls. For Google's data practices, see the Google Privacy Policy.

Security

The operator limits access to local credential files and uses Google OAuth rather than requesting the Google Account password. No website visitor receives access to the owner's token.

Consent, contact, and changes

The owner reviews and accepts this policy before using the integration. Questions or deletion requests about this integration can be sent through the Shadow Hub Discord. If data practices materially change, the operator will ask the owner to accept the updated policy before using the new practices.
