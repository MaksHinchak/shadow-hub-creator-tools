Privacy Policy

Last updated: September 23, 2026.

Shadow Hub Creator Tools is a private, locally operated integration used by the owner of the Shadow Hub channel. It uses Google's OAuth authorization and the YouTube Data, Analytics, and Reporting APIs. It is not offered as a public account service. This policy describes the operator's use of the integration; the underlying open-source package is provided by its separate maintainer.

Data accessed

Depending on the owner's authorized actions, the integration can access channel identity and metadata; videos, playlists, captions and comments; channel performance, audience and monetary analytics; and reports. It may upload owner-selected video and thumbnail files, and change video metadata or comments when the owner directs it to. The OAuth consent screen lists the permissions requested.

Purpose and use

Data is used to manage the owner's channel, publish owner-selected content, answer the owner's questions about channel performance, and help plan content. The integration does not sell YouTube API data or use it to serve ads. Visitors to this website cannot connect a Google Account or submit YouTube data here.

Storage and retention

The OAuth client configuration and authorization token are stored on the owner's computer in the ~/.youtube-mcp/ directory. The open-source integration may download a report or read a local file when requested. There is no application-operated remote database for YouTube account data. Local files and tokens remain until the owner removes them. Google may retain data under its own policies.

Processing by the assistant and third parties

When the owner uses the integration through Codex, requested API results and owner-provided instructions may be processed by OpenAI to provide the assistant response. Google processes API requests and OAuth authorization. The operator does not independently send channel data to advertisers or sell it to data brokers. The website is hosted by GitHub Pages, which may process ordinary web-request information under GitHub's own policy.

Control, revocation, and deletion

The owner can revoke the app's access from their Google Account's third-party connections at any time. To remove locally stored authorization, delete ~/.youtube-mcp/token.json; to remove the downloaded client configuration, delete ~/.youtube-mcp/client_secret.json. Any separately downloaded reports or media files must be removed from their saved locations. Revocation stops future API access but does not by itself delete files already downloaded or content already published to YouTube. For data in Codex, use the applicable OpenAI account controls. For data held by Google, see the Google Privacy Policy.

Security

The operator limits access to local credential files and uses Google OAuth rather than requesting the Google Account password. No website visitor receives access to the owner's token.

Contact and changes

Questions or deletion requests about this integration can be sent through the Shadow Hub Discord. This policy may be updated when the integration or its data practices change.
